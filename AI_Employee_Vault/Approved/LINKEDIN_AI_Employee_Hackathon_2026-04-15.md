## Post Preview

🤖 I just built my own Personal AI Employee — and it's already working autonomously!

Over the past few weeks, I've been participating in the **Personal AI Employee Hackathon 0** by @Panaversity, building a system that runs my personal and business affairs on autopilot. Here's what I've shipped:

---

🥉 **Bronze Tier — Foundation**

✅ Obsidian vault as the brain — Dashboard.md + Company_Handbook.md as live memory & rules engine
✅ Python filesystem watcher that monitors new files and triggers Claude automatically
✅ Claude Code reading from and writing to the vault (Inbox → Needs_Action → Done)
✅ All functionality packaged as reusable Agent Skills

---

🥈 **Silver Tier — Functional Assistant**

✅ Gmail Watcher — monitors inbox, creates action files for every important email
✅ LinkedIn Watcher — watches for posting triggers and automates publishing
✅ Auto LinkedIn posting to generate business visibility & sales
✅ Claude reasoning loop that creates Plan.md files for multi-step tasks
✅ Gmail MCP Server — Claude can now SEND emails as an action
✅ Human-in-the-loop approval workflow — sensitive actions always need my sign-off
✅ Cron-based scheduler for recurring autonomous tasks

---

🛠️ **Tech Stack:**
- **Brain:** Claude Code (claude-sonnet-4-6)
- **Memory/GUI:** Obsidian (local Markdown vault)
- **Watchers:** Python + UV (Gmail API, filesystem monitoring)
- **Hands:** MCP Servers (Gmail MCP, Vault MCP)
- **Automation:** Playwright for browser actions
- **Scheduling:** Cron + Task Scheduler
- **Version Control:** GitHub (bronze branch ✅, silver branch ✅)

---

This isn't just a chatbot. It's an agent that WAKES ITSELF UP, reasons through tasks, asks for approval when needed, and executes — all while I sleep.

The hardest part? Teaching it WHEN to ask for permission vs. when to just act. That's where the Company_Handbook.md (rules of engagement) comes in.

Next up: 🥇 Gold Tier — full cross-domain integration, Odoo accounting, Facebook/Instagram/Twitter, and the Ralph Wiggum autonomous loop.
