# CEO Briefing Generator — AI Employee Skill (Gold Tier)

Generate the "Monday Morning CEO Briefing" — a comprehensive weekly business health report.

## What It Covers

1. **Revenue & Accounting** — from Odoo: invoiced, paid, outstanding, expenses
2. **Task Performance** — from Vault: tasks done this week, pending approvals
3. **Social Media** — Facebook/Instagram/LinkedIn engagement summaries
4. **Bottlenecks** — overdue tasks, stuck approvals
5. **Proactive Suggestions** — AI-identified optimizations

## How to Generate

### Option A: Run the Python script directly
```bash
cd watchers
python ceo_briefing.py
```
Output saved to `AI_Employee_Vault/Briefings/YYYY-MM-DD_Monday_CEO_Briefing.md`

### Option B: Ask Claude to generate it
```
Claude will:
1. Use odoo_get_accounting_summary tool to get this month's numbers
2. Count files in /Done, /Pending_Approval, /Needs_Action
3. Read most recent social media summary from /Briefings/
4. Read Business_Goals.md for targets
5. Compose the briefing using the template below
6. Save to /Briefings/ and update Dashboard.md
```

## Step-by-Step Generation

### 1. Get Accounting Data
```
Tool: odoo_get_accounting_summary
Parameters: {month: "YYYY-MM"}
```

### 2. Count Vault Stats
```
Count files in:
- AI_Employee_Vault/Done/ (modified in last 7 days)
- AI_Employee_Vault/Pending_Approval/
- AI_Employee_Vault/Needs_Action/
- AI_Employee_Vault/Inbox/
```

### 3. Read Business Goals
```
Read: AI_Employee_Vault/Business_Goals.md
Compare actuals vs targets
```

### 4. Get Social Summary
```
Read most recent: AI_Employee_Vault/Briefings/*Social_Media_Summary.md
OR use: fb_get_page_insights tool
```

### 5. Compose and Save Briefing
```
Write to: AI_Employee_Vault/Briefings/<DATE>_Monday_CEO_Briefing.md
Update: AI_Employee_Vault/Dashboard.md (add to Recent Activity)
Log: AI_Employee_Vault/Logs/<DATE>.json
```

## Scheduling

The CEO Briefing runs automatically every Sunday at 8 PM (via cron):
```
0 20 * * 0 cd /path/to/watchers && python ceo_briefing.py >> /path/to/logs/ceo_briefing.log 2>&1
```

Or via the orchestrator's weekly schedule (configured in orchestrator.py).

## Rules

- ALWAYS source accounting data from Odoo — never estimate numbers
- ALWAYS log the briefing generation in `/Logs/`
- ALWAYS update Dashboard.md with briefing link
- NEVER include raw customer data or PII in the briefing
- Briefings are READ-ONLY reports — never trigger actions from within
- Store last 90 days of briefings in `/Briefings/`
